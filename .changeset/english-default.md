English is now the default language. With no `locale`, readable exports (`toQAList`, `toMarkdown`, `toCSV`) say "Yes"/"No", and `<FormRenderer>` uses English error messages and a "Submit" button. Brazilian Portuguese (`pt`/`pt-BR`) is still built in: pass `locale: 'pt-BR'`.
